================================================================================
ANALISE QUALITATIVA
================================================================================

Criterios para escolha da versao a apresentar no TCC:

1. PLAUSIBILIDADE FISICA da regiao bifasica:
   - bif_frac proximo de 0  ->  monofasico (improvavel para LIP)
   - bif_frac proximo de 1  ->  bifasico em quase todo simplex (irreal)
   - bif_frac em 0.2-0.6   ->  faixa fisicamente esperada

2. CONSISTENCIA COM TRINDADE: regiao bifasica menor para [DETA] que [2-HEA]

3. AJUSTE AOS DADOS DE SOUZA (calibracao):
   V1 (hexil-only):    RMSD = 0.047 (mas em 1 sistema apenas)
   V2 (base ampliada): RMSD = 0.045 (em 3 sistemas, melhor robustez)
   V3 (bounded):       RMSD = 0.055 (15% pior que V1)
